课堂知识点

import time 导入 Python 标准库 time，让程序拥有“等待”和“控制节奏”的能力。
time.sleep 控制节奏 每次 sleep 都像 Rap 的停顿，让上一句歌词停留指定秒数。
print 顺序执行 print 会按照代码从上到下的顺序，一句一句输出内容。
程序从上往下运行 Python 不会乱跳，默认按照文件顺序执行，这就是课堂第一课的核心。
